# Бесплатная публикация и обновление

В проект добавлен файл `.github/workflows/pages.yml`. Он собирает сайт из исходников и публикует только папку `dist/`.

1. Подключите аккаунт GitHub в чате или войдите на github.com.
2. Создайте публичный репозиторий `portfolio` на бесплатном аккаунте.
3. Загрузите исходники проекта в ветку `main`, включая скрытую папку `.github/`. Папку `dist/` загружать не требуется: сайт будет собираться автоматически. При загрузке ZIP сначала распакуйте его — сам ZIP GitHub Pages не распаковывает.
4. В репозитории откройте Settings → Pages → Build and deployment → Source → GitHub Actions.
5. Откройте Actions → Publish portfolio to GitHub Pages → Run workflow → main → Run workflow. При первом запуске до включения Pages ошибка исправляется повторным запуском после шага 4.
6. После успешной публикации ссылка появится в Settings → Pages и в результате задания deploy. Формат адреса для репозитория portfolio: `https://ВАШ_ЛОГИН.github.io/portfolio/`.

Оплачивать тариф GitHub или покупать домен не нужно. Исходники в публичном репозитории доступны всем. Изменение JSON с текстами или CSS в ветке main будет автоматически запускать обновление сайта.

Если имя репозитория `portfolio` уже занято в вашем аккаунте, выберите другое. Сайт использует относительные пути и поддерживает адрес с именем репозитория.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
