# Портфолио Марьям

Самостоятельный статический сайт, повторяющий портфолио на Тильде. Главная, четыре страницы кейсов, контакты, адаптивная сетка и страница дизайн-системы. Изображения и Inter хранятся локально; сайт не обращается к Тильде, Google Fonts или API. Отдельные ссылки ведут в Telegram и на сайты работодателей.

## Сначала посмотреть

Откройте `dist/index.html` двойным щелчком. Готовый сайт работает без установки программ и без сборки. Дизайн-система: `dist/design-system.html`.

Для локального HTTP-предпросмотра из папки проекта выполните:

```sh
python3 -m http.server 8080 --directory dist
```

Затем откройте http://localhost:8080. Остановка сервера: Ctrl+C.

## Где что менять

- `src/data/site.json` — приветствие, контакты, проекты, резюме.
- `src/data/one_invest.json` — содержимое One Invest.
- `src/data/alfa.json` — АльфаСтрахование Жизнь.
- `src/data/design_system.json` — кейс дизайн-системы Cloudfactory.
- `src/data/yalla_market.json` — Yalla Market.
- `src/styles/tokens.css` — цвета, шрифт, размеры, скругления, тень, отступы.
- `src/styles/site.css` — компоненты и поведение на разных ширинах.
- `public/assets/` — изображения и локальный шрифт.
- `build.py` — общие компоненты и сборка страниц. Только стандартная библиотека Python 3, без установки пакетов.
- `dist/` — готовые файлы для публикации. Их генерирует сборка; постоянные изменения вносите в `src/`.

### Поменять одну деталь

Например, цвет первого экрана: откройте `src/styles/tokens.css` в текстовом редакторе и измените `--color-accent: #bddcff;` на нужный цвет. Для текста приветствия измените поле `intro` в `src/data/site.json`. Сохраните файл и из папки проекта выполните:

```sh
python3 build.py
```

Обновите страницу браузера. После изменения данных всегда запускайте сборку.

JSON редактируется с сохранением двойных кавычек, запятых и квадратных скобок. В полях `html` допускаются абзацы `<p>`, списки `<ul><li>` и ссылки. Тексты кейсов сохранены на языке оригинала. Новое изображение положите в `public/assets/` и укажите путь `assets/имя-файла.png` в соответствующем JSON, затем пересоберите сайт.

Карточки проектов, опыт работы, кнопки, изображения, контакты и страницы кейсов собираются общими функциями в `build.py`: изменение общего компонента применится ко всем страницам.

## Размещение на обычном хостинге

1. Зарегистрируйте домен и закажите тариф, поддерживающий статические HTML-сайты. База данных и серверное приложение не нужны.
2. Добавьте домен в панели хостинга. Панель укажет корневую папку сайта (например `public_html`); точное имя зависит от провайдера.
3. Загрузите **содержимое `dist/`**, включая папки `assets/` и `styles/`, в корневую папку. `index.html` должен лежать непосредственно в ней, а не внутри вложенной папки `dist`.
4. Подключите DNS по инструкции хостинга: либо его NS-серверы у регистратора, либо указанные им записи. Не придумывайте адреса серверов.
5. Включите бесплатный сертификат SSL и перенаправление HTTP на HTTPS после подключения DNS.
6. Проверьте главную, четыре кейса, изображения, почту и Telegram с телефона.
7. Для обновления пересоберите проект и замените файлы сайта содержимым нового `dist/`.

На хостинг не нужно загружать Python, папку `src` или рабочие инструменты. Сборка выполняется на вашем компьютере. Собственный домен можно перенести к другому регистратору или хостингу.

Публикация в репозитории: можно загрузить содержимое `dist/` в корень репозитория и подключить статический хостинг. Исходники храните отдельно или в том же репозитории с настройкой сборки. Для сохранения адресов старых кейсов `/alfa` и т. п. при необходимости добавьте правила перенаправления на новые `.html`-адреса в панели хостинга. Текущий `*.tilda.ws` принадлежит Тильде и не переносится к другому хостингу.

## Примечания к первой версии

Сохранены тексты и исходные изображения пяти страниц. Разметка заново собрана без библиотек Тильды. На телефонах блоки перестраиваются в поток. Добавлены клавиатурный фокус и переход к следующему кейсу. Кастомный курсор оригинала пока не перенесён. Изображения с интерфейсами остаются растровыми: чтобы поменять надпись внутри скриншота, нужно заменить изображение. Редактирование файлов — текстовое, визуальная административная панель в эту версию не входит.
